About PageForge

PageForge is the instructor example project used to show how a web project can grow through small weekly changes.

What Week 9 Demonstrates

  • Modularity as a design habit
  • Multiple JavaScript files with separate responsibilities
  • Script loading order
  • Preparing the project for data and state growth

What Is Still Deferred

This version does not use formal ES modules yet. It uses ordinary script tags so the difference between modularity and module syntax stays clear.

PageForge is built to support visible iterative development.
