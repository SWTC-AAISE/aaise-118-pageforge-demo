About the project

About PageForge

PageForge is the instructor example project used to show how a web project can grow through small weekly changes.

What Week 6 Demonstrates

  • Checking selectors and script loading order
  • Using console messages to follow program flow
  • Updating all related page regions after a change
  • Guarding against missing block data

What Is Still Deferred

Blocks can be added and removed, but they cannot be edited, reordered, or saved yet. The goal is reliability of the current interaction, not feature growth.

PageForge is built to support visible iterative development.
