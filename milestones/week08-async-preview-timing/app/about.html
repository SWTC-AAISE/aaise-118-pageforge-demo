About PageForge

PageForge is the instructor example project used to show how a web project can grow through small weekly changes.

What Week 8 Demonstrates

  • Immediate code and delayed code
  • setTimeout() as a visible timing example
  • Status messages that explain what the app is doing
  • Preparation for later fetch() and JSON loading

What Is Still Deferred

This version does not load external data yet. It only makes the timing problem visible so requests and future results feel less mysterious later.

PageForge is built to support visible iterative development.
