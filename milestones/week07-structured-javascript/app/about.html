About the project

About PageForge

PageForge is the instructor example project used to show how a web project can grow through small weekly changes.

What Week 7 Demonstrates

  • Separating data, DOM references, actions, and rendering
  • Using function names to explain intent
  • Refactoring without changing the user-facing behavior
  • Preparing code for larger features in later weeks

What Is Still Deferred

Blocks can be added and removed, but they cannot be edited, reordered, or saved yet. The goal is clearer organization before the project grows into async, data, state, and forms.

PageForge is built to support visible iterative development.
