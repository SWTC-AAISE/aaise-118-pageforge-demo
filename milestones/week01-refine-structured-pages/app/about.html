About PageForge

PageForge is the instructor example project used to show how a web project can grow over time. It begins with simple HTML structure and will expand later with CSS, layout, and JavaScript.

Instructional Goals

  • Show how a project starts with simple structure.
  • Model steady growth from week to week.
  • Keep each milestone readable and appropriate to its stage.

Current Limits

This version does not include styling, interactivity, block editing, live preview, or export features. Those ideas are intentionally deferred so the project can begin with a truthful HTML-only foundation.

PageForge is a teaching project built to support iterative development.
