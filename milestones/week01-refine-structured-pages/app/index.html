PageForge

PageForge is the instructor demonstration project for a browser-based webpage composer. In this first build milestone, it exists as a simple multi-page site with clear structure.

What This Version Includes

  • Three HTML pages
  • Navigation between pages
  • Basic headings, paragraphs, and lists
  • An early builder page that suggests the future app layout

What Will Come Later

Later milestones will gradually add the ability to:

  • choose predefined webpage blocks
  • edit content inside those blocks
  • preview a composed page
  • view or export generated code

Week 1 build milestone: project structure only.
