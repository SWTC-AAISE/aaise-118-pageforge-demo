About the project

About PageForge

PageForge is the instructor example project used to show how a web project can grow through small weekly changes.

What Week 5 Demonstrates

  • DOM selection with querySelector
  • Creating page elements from JavaScript data
  • Click event listeners
  • Updating visible content after user action

What Is Still Deferred

Blocks can be added, but they cannot be edited, removed, reordered, or saved yet. Those behaviors are intentionally saved for later milestones.

PageForge is built to support visible iterative development.
