About PageForge

PageForge is the instructor example project used to show how a web project can grow through small weekly changes.

What Week 4 Demonstrates

  • JavaScript variables and constants
  • Arrays and objects used to describe block types
  • Conditions that choose status messages
  • Functions that organize small pieces of logic

What Is Still Deferred

The buttons do not add blocks yet. The preview is static. This version is about understanding the data and decisions that later interaction will depend on.

PageForge is built to support visible iterative development.
