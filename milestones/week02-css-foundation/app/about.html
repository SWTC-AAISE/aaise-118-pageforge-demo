About the project

About PageForge

PageForge is the instructor example project used to show how a web project can grow through small weekly changes.

Why This Project Exists

The class can revisit one consistent project instead of starting over each week. This makes it easier to see how HTML, CSS, and JavaScript connect inside a larger build.

What Week 2 Demonstrates

  • One shared stylesheet for multiple pages
  • Color, type, spacing, and border choices
  • Reusable classes for repeated visual patterns
  • A more polished but still static project state

What Is Still Deferred

Responsive layout, JavaScript logic, block editing, live preview, templates, and export features are still future milestones.

PageForge is built to support visible iterative development.
