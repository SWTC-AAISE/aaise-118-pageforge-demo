Build a page, block by block.

PageForge is a browser-based webpage composer that will grow across the course. This week adds a shared stylesheet, color, spacing, and a more readable visual identity.

Preview the Builder Plan

What This Week Adds

Shared Styles

Each page links to the same CSS file so the site feels like one connected project instead of three separate documents.

Readable Spacing

Headings, paragraphs, sections, and navigation receive enough space to make the content easier to scan.

Reusable Classes

The project starts using class names such as section, card, and button to style repeated patterns.

Still Intentionally Static

The builder is not interactive yet. PageForge is still practicing HTML and CSS foundations before JavaScript enters the project.
