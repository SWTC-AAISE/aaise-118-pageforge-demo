# PageForge In-Class Demo

This repository is the staged instructor demonstration for 10-152-118 Web Development Foundations.

It begins with the Week 1 build foundation from the canonical [PageForge](https://github.com/cashmy/PageForge) project at commit `84ef099fc23ddab8d69d512422fb2723a82a9f02`.

The `app/` directory is runnable as the current classroom stage. The `docs/` directory records the instructional context for each released stage.

Students use this repository as a reference example. They build their own projects rather than copying PageForge.
